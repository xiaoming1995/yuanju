## Context

当前“我的”页已绑定卡片使用 `toHistory` 的四组完整干支文本，横向显示在默认名称下方。全局卡片边框和圆角已有跨页规范；结果页原局使用暖白表面、深棕正文与浅金线条。用户批准的单卡设计稿位于本会话视觉稿 `personal-chart-original-palette.png`。

## Goals / Non-Goals

**Goals:** 在已绑定状态复现设计稿的单卡结构，保持窄屏与字体增大时可读，维持现有导航和状态处理。

**Non-Goals:** 改动八字数据、后端接口、其他页面卡片或全局色彩规范。

## Decisions

1. 只修改“我的”页局部 WXML/WXSS；共享边框仍取全局变量。已绑定时以四列展示年、月、日、时，每列把天干和地支上下排列，并以浅米色背景强调日柱。其他状态保留原有内容结构。
2. `toHistory` 为每列同时提供 `gan`、`zhi` 和既有 `text`，供此卡片分别渲染两字；其他调用方继续使用 `text`。默认名称“我的干支”不重复展示，实际自定义名称可作为次级文本出现。
3. 详情沿用整卡点击，修改资料沿用独立 `catchtap`。出生日期和次级操作位于底部，卡片标题与四柱区域以细线分隔。

## Risks / Trade-offs

- [字体放大时四列挤压] → 按四等分分配列宽，字符独立居中；在窄屏下压缩留白而非截断干支。
- [默认名称与自定义名称混淆] → 只隐藏确切的默认文案，真实自定义名称仍展示。
- [卡片外观与其他页面不一致] → 保留全局外边框与圆角，仅在卡内采用结果页色调。
