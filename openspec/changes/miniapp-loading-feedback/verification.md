## 入口与就绪点（实现前）

| 页面 | 跨页操作 | 本地即时操作 | 可用于确认目标已显示的时机 |
| --- | --- | --- | --- |
| 首页 | 查看固定示例 → 结果页；查看日历 → 日历 Tab | 查询／历史切换、日期选择、历史弹层与临时移除 | 结果页首次 `onReady`；日历 Tab 的 `onShow`／首次 `onReady` |
| 日历 | 打开每日参考、择日页 | 切月、选日、日期／节气切换、启用演示 | 每日参考或择日首次 `onReady` |
| 结果 | 返回首页，失败时切换首页 Tab | 无需等待的静态示例展示 | 首页 `onShow` |
| 每日参考 | 结束体验后返回日历，失败时切换日历 Tab | 启用演示 | 日历 `onShow` |
| 择日 | 打开日期详情 | 事项／日期范围切换、分段展示 | 每日参考首次 `onReady` |
| 我的 | 查看演示历史 → 首页 Tab | 登录态演示、弹层与工具提示 | 首页 `onShow` |

原型没有网络请求；首页、日历、结果、每日参考和我的主要数据均在本地。择日结果最多分析 90 天，结果列表分组后每组先显示 7 天。首次页面准备时间与 WXML 绘制时间仍需设备环境确认。

## 实测与环境边界（实现前）

- 本地 Node 对最长 90 天搬家演示计算运行 100 次：中位数约 0.221 毫秒，P95 约 2.189 毫秒。此数据不包含微信渲染、设备性能或页面跳转。
- 本机微信开发者工具 CLI 执行 `open --project .../miniapp --port 31257` 返回内部 `ERR_SOCKET_BAD_PORT`（收到端口 65536），尽管进程退出码为 0；因此未取得当前模拟器的冷进入、再次进入或画面耗时。
- 项目配置使用 `touristappid`，本轮没有可用的真机预览身份；手机耗时与窄屏实际渲染仍待验收。

## 实施后的反馈边界

- 六个页面的跨页入口共用一次导航状态：点击立即改变入口样式；目标超过 200 毫秒仍未就绪才显示「正在打开…」；就绪、返回、失败或 8 秒超时会清理提示。失败与超时使用「打开失败，请重试」提示。
- 六页当前都使用随包本地数据，页面主要内容在定义或同步生命周期中生成；没有目标页可见后等待网络或异步内容的路径。因此本次没有给快速静态页面叠加骨架占位。日后接入异步数据时，应在对应页面增加卡片占位、空状态和失败重试。
- 择日 90 天本地分析本身耗时很短，不人为延迟计算。事项、范围与结果在同一次 `setData` 中提交；若视图更新 200 毫秒后仍未完成，仅在结果区域显示「日期结果更新中…」。8 秒仍未完成时改为重试状态，离开页面会取消计时。
- Node 测试覆盖快速与较慢跳转、重复点击、失败、超时、返回、Tab 切换、结果更新和取消；其模拟的页面就绪与 `setData` 回调不等同开发者工具或真机实测。
