## Why

结果页已计算出天干级喜忌，但首屏仍突出显示“金土火”“水木”等五行总方向。用户在最先阅读结论时无法直接看出应优先关注哪个天干，天干级结果被放在后续专业区，未解决总览过于泛化的问题。

## What Changes

- 用已有的天干级指导替换结果页首屏的五行级扶抑徽标，按“首取、扶抑可用、扶抑慎用”展示可用的具体天干。
- 将日干调候与扶抑交集的主喜天干作为首取项，并显示其十神及共同来源。
- 将仅由扶抑支持或反对的天干以完整、不重复的列表展示；没有共同首取时，明确标示为扶抑可用，而不虚构优先级。
- 保留专业区的详细理由、调候结构冲突说明和现有 API 五行字段，不改变扶抑、原局等级、大运道路或流年评分。

## Capabilities

### New Capabilities
- `stem-level-yongshen-summary`: 在八字结果首屏以精确、分层的天干级喜忌摘要替代泛化五行徽标。

### Modified Capabilities
- None.

## Impact

- 前端：`frontend/src/pages/ResultPage.tsx` 和 `ResultPage.css` 的结果总览标签与响应式布局。
- 数据：消费既有 `natal_assessment.stem_guidance`，不新增接口字段或修改后端判定。
- 测试：结果页摘要显示、无共同主喜的回退、移动端文字换行以及现有评分不变的回归覆盖。
