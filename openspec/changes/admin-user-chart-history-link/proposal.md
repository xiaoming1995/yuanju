## Why

后台用户列表能显示累计查盘次数，但管理员无法从某个用户直接查看其排盘记录；全站明细目前只支持邮箱搜索，无法准确定位没有邮箱的微信用户。用户删除命盘后，现有记录会消失，也无法看到那次查询发生过。

## What Changes

- 点击用户列表中的用户名或“累计查盘”数字，进入仅展示该用户命盘记录的起盘明细页；用户详情也提供入口。
- 管理员起盘列表 API 增加可选的精确用户 ID 筛选，保留现有分页和日期筛选。
- 对已登录用户持久记录每次成功查盘的时间；命盘删除后保留最少的历史信息，只显示时间和“已删除”，不保留生辰与命盘内容。
- 页面清楚标注当前用户范围，列出现存与已删除的查询记录，并允许返回全站列表。

## Capabilities

### New Capabilities

- `admin-user-chart-history-link`: 从后台用户管理跳转到按用户 ID 筛选的起盘记录列表。

### Modified Capabilities

无。

## Impact

- 数据库迁移、起盘创建与删除事务、账号合并、管理员起盘列表仓储及 HTTP 查询参数、前端管理员 API、用户列表和起盘列表页面；无新依赖。
