## ADDED Requirements

### Requirement: 用户列表展示当日问事额度与使用
后台用户管理列表 SHALL 对每位当前页用户显示北京时间今天的已用次数、剩余次数、免费已用/免费上限与额外余额；处理中请求 SHALL 单独标识。今日已用 SHALL 包含已计费的成功和「依据不足」回答，不包含失败、已退回或历史未计费请求。剩余次数 SHALL 扣除免费处理中预占，并计入仍可使用的额外余额。列表 SHALL 只供管理员查看，分页、搜索及筛选不得串入其他用户的数据。

#### Scenario: 免费额度与额外次数同时存在
- **WHEN** 每日免费上限为 1，用户今天免费成功 1 次、额外成功 1 次，额外余额为 3
- **THEN** 用户列表显示已用 2、剩余 3、免费已用 1/1、额外余额 3

#### Scenario: 处理中与技术失败
- **WHEN** 用户有一笔仍在处理的免费问事，另一笔 AI 技术失败已退回
- **THEN** 处理中单独显示，免费剩余额度扣除处理中预占；失败不计已用或占用

#### Scenario: 北京时间跨日与配置调整
- **WHEN** 北京时间进入次日，或管理员调整全员每日免费上限
- **THEN** 列表刷新后按新的北京时间日期和最新免费上限计算，不清除额外余额

#### Scenario: 超时回收与分页隔离
- **WHEN** 当前页用户有超过十分钟的处理中请求，或列表按搜索条件只返回部分用户
- **THEN** 超时请求按现有规则退回后再统计；响应只含当前页用户的用量
