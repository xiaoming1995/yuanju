## Context

当前 `buildPersonalDayThemes` 仅追加命中的“宜／慎”项，`personalThemes` 又只过滤这两个等级。2026-11-04 本地已绑定命盘的服务端结果只含投资运、健康运，和用户对固定四项的预期不一致。

## Goals / Non-Goals

**Goals:** 有效个人命盘每天完整返回与展示四项，并让无特殊信号的“平”明确表示检查过但未触发特定规则。

**Non-Goals:** 将“平”解释为好运、健康保证或投资判断；在关键命盘资料缺失时虚构结论。

## Decisions

每个主题先构造有来源、证据和行动建议的中性结果，再按既有规则覆盖为“宜／慎”。财务复用 `domainGuidance`，中性或未命中特别方向时统一展示“平”，并补足可查看依据。小程序接受有证据的 `neutral` 级别，仍拒绝 `insufficient`。保持四项固定顺序和原有 API 字段，旧客户端兼容。

## Risks / Trade-offs

- [“平”被误解为绝对安全] → 文案明确“未触发当前规则”，不声称无风险。
- [旧服务端缺新字段] → 维持“主题参考暂不可用”，不使用旧事项冒充四主题。
- [无效命盘] → 不生成四条中性结果，遵循原有资料不完整状态。
