## Context

当前 `BuildPersonalDay` 已有日期干支、通用宜忌、本人喜忌、十神、日支相冲和结构化 `activity_guidance`。首页与详情过滤后仅显示旅行、财务、工作、沟通中的“宜／慎”。命盘算法另有天乙贵人、桃花的静态规则，但每日服务尚未调用。

## Goals / Non-Goals

**Goals:** 按本人命盘和单日干支生成四主题、可追溯、有具体行动建议的个人提示；无命中项直接隐藏；首页与详情同源。

**Non-Goals:** 预测具体贵人、约会结果、投资收益、疾病或交通意外；使用对方命盘；把通用黄历标签转换为个人结论。

## Decisions

1. 给个人每日结果增加 `theme_guidance`，保留既有 `activity_guidance` 兼容旧客户端。小程序新界面只读新字段；旧服务端缺该字段时显示“今日参考暂不可用”，不自行推断。
2. 主题只在规则命中时输出。贵人：本人年干或日干与当日日支的天乙贵人关系；桃花：本人年支或日支对应的桃花支与当日日支相同，或当日日支与本人日支六合。两者只解释为社交/协作的传统参考；当日日支主气为忌神、存在调候分歧或与本人日支相冲时降为“慎”并列出冲突依据。
3. 财务沿用已有正偏财／比劫十神与喜忌方向的规则，仅使用有方向的 `candidate`／`review` 结果。文案改为研究、预算、合同与风险检查；不提供交易动作。健康只在当日日支冲本人日支或当日日干、日支主气均落入忌神时显示“慎”，给出休息、行程余量等一般行动建议。过马路留意车辆属于通用安全建议，绝不表述为命盘预测事故。
4. 主题结果沿用 `PersonalDayGuidance` 的 ID、标题、等级、摘要、来源、证据结构，增加 `actions` 列表供详情展示。首页只显摘要；详情显示建议和可展开证据。保留原有整体干支关系与方位色彩区域。

## Risks / Trade-offs

- [四主题规则较轻量] → 结果只表述为传统文化参考，不作事件概率或确切吉凶排名。
- [某日无主题命中] → 整区显示“今日暂无特别提示”；不制造“未列”或“平”。
- [旧服务端无新增字段] → 显示暂不可用状态，不用旧事项伪装新主题。
- [前端首页有未提交改动] → 只编辑本人事项区域，保留其余改动。

## Migration Plan

先部署后端加法字段，再部署小程序。回退小程序仍可读取旧 `activity_guidance`；回退后端时新小程序显示暂不可用，不产生错误判断。无需数据库迁移。

## Open Questions

无阻塞问题；后续若要更细分贵人和桃花，可在现有主题规则上扩展，而不改变字段形状。
