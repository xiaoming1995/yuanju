## Context

首页分别展示当日干支关系与四项本人每日主题。此前鼓励语只依据干支关系状态；截图中「日干偏合」触发轻正向语句，而四项主题全为「平」，形成冲突。

## Goals / Non-Goals

**Goals:** 首页短句与同屏四项主题的实际基调一致，保持已有关系状态的谨慎边界。

**Non-Goals:** 不重新计算四项主题，不修改后端算法，也不把四项主题合成数值分数。

## Decisions

首页先使用已有 `personalThemes(day)` 取得与页面完全一致的四项主题，再传给鼓励语映射。四项资料不完整时不显示总括短句。当天关系为 `caution` 或含单边忌神时继续谨慎；`mixed` 继续平稳。其余状态下，任一主题为 `review` 时不得积极；四项全为 `neutral` 时显示平稳；至少一项 `candidate` 且无 `review` 时，才按双喜用或单边喜用选择强、轻积极语句。页面布局和详情入口不变。

## Risks / Trade-offs

- [主题短句与页面内容再次不一致] → 映射直接使用页面展示的同一份过滤结果，并以截图组合建立回归测试。
- [旧接口缺少主题] → 不显示总括短句，保留已有分项与详情。

## Migration Plan

仅小程序展示映射变化，无数据库或 API 迁移。
