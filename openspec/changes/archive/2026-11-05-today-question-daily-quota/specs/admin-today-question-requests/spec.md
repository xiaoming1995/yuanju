## ADDED Requirements

### Requirement: 管理员可调整今日问事每日次数
今日问事专属管理页 SHALL 显示当前每人每日次数及北京时间重置规则，并允许持 Admin JWT 的管理员保存 1—100 的整数。保存失败时 SHALL 显示错误且不得假装生效。

#### Scenario: 保存每日次数
- **WHEN** 管理员将次数修改为有效整数并保存
- **THEN** 页面显示已生效的值，后续用户请求按新值限制

#### Scenario: 非管理员或非法数值
- **WHEN** 普通用户访问设置 API，或管理员提交 0、非整数或超过上限的值
- **THEN** 系统拒绝并保持原设置
