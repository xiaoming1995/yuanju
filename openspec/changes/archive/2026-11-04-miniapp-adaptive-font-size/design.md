## Context

小程序八个页面和全局 WXSS 中有大量固定 `rpx` 字号；只更改 `page` 字号不会影响它们。“我的”页已有“设置与帮助”列表，可直接放入字体设置。当前没有字体偏好或后端字段。

## Goals / Non-Goals

**Goals:** 增大默认可读字号；跟随微信字号；允许本机手动覆盖；各页面切换后立即一致；大字下不截断核心内容。

**Non-Goals:** 账号跨设备同步、网页端和管理后台字号设置、控制微信原生 tabBar 字号。

## Decisions

- 使用 `wx.getAppBaseInfo()` 的 `fontSizeSetting`（旧环境降级到 `wx.getSystemInfoSync()`），换算为受限倍率；不可用时使用标准倍率。每次页面 `onShow` 重新读取，以接收从微信设置页返回后的变化。
- 本机只存储模式 `follow | standard | large | extra`。默认 `follow`，手动模式覆盖微信字号；未登录也可使用，退出登录不清除偏好。
- 提高页面固定字号的基础值，并通过页面根节点的 CSS 字号增量统一调整文字。字号与容器尺寸分开处理；日历等紧凑结构有针对性换行/增高。
- “我的”设置行展示当前模式，点击弹出四项选择并即时应用。无需新页面或后端接口。

## Risks / Trade-offs

- WXSS 动态字号在不同微信环境的渲染可能有差异 → 保留基础字号回退值，检查开发者工具及真机。
- 特大字可能使固定宽度或高度内容溢出 → 检查日历格、命盘四柱、按钮和长文案，允许可读文本换行。
- 微信系统字号可能超出预期范围 → 对换算倍率设置上下限。
