## Why

现有小程序首页能展示当天通用黄历和本人每日主题，但用户遇到「今天面试该如何准备」这类具体事情时，仍需自己把日期提示与问题关联起来。新增仅限当天的本人问事入口，让用户获得有依据的有利程度和可执行建议，同时避免把命理参考伪装成事件成功概率。

## What Changes

- 在小程序现有首页日期区域之后、黄历宜忌之前增加同风格「今日问事」入口；保留现有日期、黄历、本人每日主题、方位色彩和底部导航布局。个人每日详情可提供同一问事入口。
- 已登录且绑定本人命盘的用户可选择受支持事项并输入一个当天的具体问题；后端以北京时间确定并校验当天，读取当前账号绑定的命盘。
- 后端组织原局、大运、流年、流月、流日及与所问事项有关的可核对依据，AI 只基于这些资料生成有利程度、支持与冲突依据、准备建议和不确定性说明。没有足够依据时明确返回「依据不足」。
- 不提供数字成功率、录用或其他具体事件的结果保证；不把通用黄历宜忌冒充个人判断。首版支持面试、工作沟通、重要出行、见面社交，其他问题不强行套用结论。
- 未登录或未绑定时入口仍可见，进入后引导登录或设置本人命盘；账号、命盘或北京时间日期变化时清除过期的提问状态与结果。

## Capabilities

### New Capabilities

- `miniapp-today-question`: 限当天的事项提问、命理依据组织、AI 回答契约及状态边界。

### Modified Capabilities

- `miniapp-home-daily-guidance`: 首页在现有分层内容中增加「今日问事」入口，并维持原有模块来源与显示顺序。

## Impact

- 小程序首页、个人每日详情、问事页面与 API 请求层；后端用户鉴权路由、handler、service、AI Prompt 配置及必要的结果存储或调用日志。
- 复用本人命盘、`BuildPersonalDay`、大运和流年数据、流月计算及现有 LLM Provider 调用机制；不新增命理计算依赖，不改变通用黄历或现有每日主题的判断口径。
