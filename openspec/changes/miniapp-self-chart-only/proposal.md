## Why

小程序首页的任意生辰排盘入口与以本人命盘为中心的使用场景不一致，也让用户能够从未绑定的记录进入命盘详情。需要把小程序收敛为配置、查看本人命盘的体验，同时保留首页的日历内容。

## What Changes

- **BREAKING** 删除小程序首页截图红框内的整块“出生信息排盘”区域，包括标题、历史入口、日期/性别/备注表单、日期选择器和排盘按钮；不以新的首页命盘卡片替代。保留“今日干支”及其后的首页内容。
- 在「我的」提供首次配置本人出生资料的入口；保存后建立该账号唯一的本人命盘绑定。已绑定用户可以查看、修改或解绑本人命盘。
- 小程序命盘详情仅展示当前账号已绑定的本人命盘；未登录或未绑定时引导登录或配置。历史中已有的其他记录不再提供详情查询入口，但保留存量数据。
- 删除「我的」页重复的“我的排盘”列表卡片；保留上方本人命盘卡片。调整首页及历史入口，使它们不能绕过本人命盘限制。服务端校验详情读取与当前账号的绑定关系。
- 网页端的通用排盘能力及既有数据不在本变更范围内。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `miniapp-backend-integration`: 小程序从任意生辰排盘及通用历史详情，改为本人命盘配置和受绑定约束的详情访问。
- `miniapp-personal-chart-daily-guidance`: 首次配置与后续修改本人命盘的流程改变；保留唯一绑定及每日参考依赖本人命盘的规则。

## Impact

- 小程序首页、我的、命盘详情及导航与 API 调用层；相关小程序检查。
- 后端本人命盘配置和详情接口、归属及绑定校验；相关处理器、仓储与检查。优先复用现有排盘计算与本人命盘表。
- 不删除历史记录，不引入新依赖。现有 `miniapp-home-visual-refinement` 仍处于进行中，实施时需对照当前文件和该变更，避免重新引入首页表单。
