## Context

首页每日参考采用暖白纸面、浅金细边、深棕标题与少量绿色行动强调。全局 `miniapp/app.wxss` 已提供页面纸张背景、梅枝与远山、`.surface-card`、`.section-heading` 和 `.primary-button`；各功能页在这些基础上又分别定义大面积深色主视觉、冷灰文字和不同的卡片装饰。已有首页、日历和“我的”视觉变更，实施必须以当前代码及最新画面为基线。

## Goals / Non-Goals

**Goals:**
- 从首页进入日历、今日完整依据、择日、排盘结果和“我的”相关页面时，保持稳定的纸张色调、标题与卡片节奏。
- 用文字大小、留白和少量金色细节区分重点，保障长数据和窄屏可读。
- 让加载、失败、空内容、未登录和未绑定状态融入同一视觉规则。

**Non-Goals:**
- 修改历法、八字与每日参考计算，或改动 API、登录和导航逻辑。
- 让所有卡片复制首页重点卡的双层边框和装饰。
- 引入组件库、设计依赖或重新制作背景图片。

## Decisions

### 1. 以现有全局基础为底，按页面局部收敛

保留共享纸张背景与三项基础类。先统一页面局部样式，只有当相同规则在多页反复出现且不会影响首页时，才抽取少量全局样式。相比一次性替换所有局部 WXSS，这能减少对日历复杂状态及结果网格的意外影响。

### 2. 区分重点展示卡、普通内容卡和控件

首页日期与三张每日参考卡是视觉基准。今日详情与择日顶部采用浅色纸面抬头；跨页外层卡片共享首页的 1rpx 浅金边线和 26rpx 圆角，通过阴影与内容留白区分重点和普通卡片。结果矩阵、日历格和表单输入属于卡内控件，保留较轻的选中与网格边界。金色仍集中用于日期重点及操作提示。

### 3. 保持语义颜色，收敛装饰颜色

宜与忌继续使用绿与红，五行继续保持可辨的各自色彩，警示及不可用状态保持独立。结果页无业务语义的紫色装饰和跨页冷灰底色改用首页的暖色文字与纸面色阶；不能仅靠颜色区分状态，已有标签文字与说明保持可见。

### 4. 按跨页路径验收真实内容

优先检查“首页→日历→今日详情”、“日历→择日”与“我的→排盘结果”三条路径。页面需覆盖长宜忌、长事项、五行与四柱数据、网络失败、空状态、未绑定及字体增大；在常见和窄屏设备上检查点击区域、折行与安全区。截图或实机画面是视觉验收依据，静态检查只能确认结构与行为。

## Risks / Trade-offs

- [全局类调整波及其他页面] → 优先使用页面作用域，确需抽取时逐页检查使用处。
- [纸张装饰使长内容显得拥挤] → 只在顶部与重点卡使用强化边线，正文卡以留白分组。
- [改动颜色后业务意义模糊] → 宜忌、五行及风险状态逐项核对文字和颜色。
- [旧视觉变更尚未完成窄屏检查] → 在实施与验收时把最新首页画面和历史态一并核查。

## Migration Plan

仅发布小程序 WXML/WXSS 视觉调整，无数据迁移。按页面分组落地并检查跨页路径；若某页布局回归，可回退该页局部样式而不影响数据。
