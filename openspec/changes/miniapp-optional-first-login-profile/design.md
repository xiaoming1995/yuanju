## Context

“我的”页在 `loadProfile()` 发现微信账号的默认昵称或空头像时，自动将 `profileEditorVisible` 设为 true。编辑器已有主动打开入口、保存与取消逻辑。

## Goals / Non-Goals

**Goals:** 回访登录及资料刷新默认关闭编辑器；未完善资料的账号仍能显示默认资料并主动编辑。新建账号引导由 `miniapp-first-login-profile-autosave` 处理。

**Non-Goals:** 自动读取微信头像昵称、修改登录及后端资料接口。

## Decisions

- `loadProfile()` 仅保留当前已打开的编辑状态，不根据资料是否完整自动打开。新建账号引导由登录响应决定，回访登录不会重复弹出。
- 保留 `profileIncomplete` 用于编辑器内部提示，但顶部账号区显示正常昵称和账号说明。取消编辑器时统一显示“取消”。
- 保持头像和昵称各自可独立更新。首次只选其中一项即可保存，另一项继续使用默认资料；既有两个独立接口支持此流程。

## Risks / Trade-offs

- 用户可能不知道可改资料 → 顶部资料区继续保留点击入口和箭头，并在账号说明中提示可修改。
- 开发者工具中微信头像昵称选择行为与真机可能不同 → 保留现有模拟测试，发布前再用真机确认。
