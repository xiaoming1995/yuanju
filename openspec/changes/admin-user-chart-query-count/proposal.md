## Why

后台用户页当前的“干支数”来自尚未删除的命盘记录，不能回答某个用户累计成功查询过多少次盘。管理员需要看清这个累计次数，同时区分现存记录数。

## What Changes

- 对已登录用户每次成功创建的八字排盘累计一次查询次数；重复查询同一生辰也分别累计，删除命盘不减少次数。
- 已登录用户保存排盘失败时返回错误，避免成功响应却不累计次数。
- 用现存命盘数初始化老用户计数，并明确历史已删除命盘无法追溯。
- 后台用户列表与详情显示“累计查盘次数”，详情保留现存排盘和合盘数。

## Capabilities

### New Capabilities

- `admin-user-chart-query-count`: 已登录用户的累计查盘计数及后台展示口径。

### Modified Capabilities

无。

## Impact

- 数据库迁移、八字创建事务、管理员用户查询及后台用户页面。管理员 API 增加字段，不改变现有字段；不引入新依赖。
