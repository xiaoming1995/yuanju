# 缘聚微信小程序

小程序的账号、八字计算、干支历史和个人中心使用与网页端相同的后端和 `users.id`。月历标签使用随包数据；择日参考读取服务端真实通用宜忌。登录用户主动绑定本人命盘后，每日干支个人参考由后端计算。

## 后端接入

### 本地开发者工具联调

1. 在 `backend/.env.docker` 填入真实 `WECHAT_MINIAPP_APP_ID`、`WECHAT_MINIAPP_APP_SECRET`（可参考 `.env.docker.example`），然后从仓库根目录运行 `./scripts/docker-compose-up.sh backend`，用 `curl http://127.0.0.1:9002/health` 确认后端可访问。必要时执行 `docker compose -f docker-compose.yml -f docker-compose.local.yml exec backend ./server -migrate-apply` 并检查迁移结果。
2. `miniapp/config.js` 自动按小程序版本选择地址：开发版在开发者工具模拟器中使用 `http://127.0.0.1:9002`，开发版真机使用电脑的局域网 IP；体验版和正式版使用 `https://www.guanshilu.cn`。开发者工具需开启“本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。项目 AppID 必须与后端一致；若仍为 `touristappid`，则不能测试真实微信登录。
3. 在“我的”中点击“微信一键登录”；首次登录自动创建小程序账号。需要沿用已有网页账号时，登录后在个人中心选择“绑定已有网页账号”，填写邮箱密码并合并两端历史。小程序新用户注册默认开启；若本地数据库此前已将开关保存为关闭，需在网页后台用户列表中重新开启。
4. 首次微信注册由后端生成“缘友＋6 位随机数字”的默认昵称（例如“缘友582731”），只在新建账号时生成，后续登录及已有账号昵称保持不变。新用户进入独立“个人资料”页，也可直接返回继续使用；后续登录不重复打开引导。用户随时可点击“我的”顶部资料区进入该页：头像选择后立即保存，修改昵称并移开焦点、通过微信检查后自动保存，两项互不等待，无需保存或取消按钮。字段下方显示保存状态，失败可单独重试；保存后留在当前页，返回“我的”时刷新展示。尚有未保存修改时，平台支持的返回操作会询问是否离开。`wx.login` 只用于获取身份凭证，不会自动返回微信个人头像与昵称。

手机与电脑在同一局域网时，`miniapp/config.js` 中的 `lanApiBaseUrl` 应填写电脑的局域网 IP，例如 `http://192.168.101.24:9002`，用于开发版真机联调；先用手机浏览器访问 `http://电脑局域网IP:9002/health` 确认网络可达。电脑 IP 变化后需同步修改。`0.0.0.0` 是服务端监听地址，不能作为小程序请求地址；`127.0.0.1` 仅供开发者工具模拟器使用。体验版和正式版使用 HTTPS 域名，不受局域网 IP 变化影响。

开发者工具 3.17.5 的微信昵称检查可能报 `reviewNickname:fail upload nickname timeout`，且错误地把超时标志设为 false。页面会保留输入并提供“重试检查”，不会把服务异常直接提示为昵称不合规，也不会在未明确通过时提交。若持续超时，需检查开发者工具到微信服务的网络，或使用已配置 HTTPS 后端的真机核对。

### 发布配置

1. 后端应用迁移 `00027_miniapp_user_identity.sql` 和 `00028_user_avatar.sql`，在后端环境设置 `WECHAT_MINIAPP_APP_ID` 和 `WECHAT_MINIAPP_APP_SECRET`。密钥仅保留在后端，不能写进小程序源码。头像文件保存在后端 `UPLOAD_DIR/user-avatars`，部署时需保留该目录的持久化存储。
2. `miniapp/config.js` 已把体验版和正式版的 API 地址固定为 `https://www.guanshilu.cn`，每次上传无需手动切换；若将来更换域名，只改 `productionApiBaseUrl`，不要加 `/api`。前端 Nginx 会转发 `/api` 和 `/static` 到后端；微信小程序后台需将 `https://www.guanshilu.cn` 配为 request 与 uploadFile 合法域名。上传体验版后用真机检查登录和头像上传，确认请求发往线上地址。
3. 核对 `miniapp/project.config.json` 中的 `appid` 与后端配置一致。首次微信建号默认开启，可在网页管理后台“用户列表”中单独关闭“小程序微信注册”；网页邮箱注册开关独立。
4. 小程序登录后，可在“我的”中选择绑定已有网页账号。验证网页密码后，后端在一个事务中将小程序账号的干支、合盘、收藏及用量记录迁到原网页用户 ID，并把微信身份转到该 ID；返回新令牌后，两端共享历史。密码错误或目标账号已有冲突的微信身份时，不合并。
5. 小程序只在用户点击登录后调用 `wx.login`。排盘要求登录并保存至用户历史；通用日历与择日参考无需登录，也不会写入用户历史。
6. “我的”页公众号入口默认关闭。先在网页管理后台「系统配置 → 公众号引导」上传真实公众号二维码，填写名称、可搜索微信号和简短说明；上传图片后还需点击「保存配置」才会生效。二维码保存在后端 `UPLOAD_DIR/official-account-qr`，与现有上传目录共用持久化卷。正式启用前，用 iPhone 和安卓微信真机分别核对图片预览与长按表现；小程序始终提供“复制微信号”搜索路径，不保证长按图片可直接关注。不要上传设计稿中的示意二维码。

发布前还需配置正式隐私政策，说明用户主动提交的头像与昵称的用途；并用真实 AppID、AppSecret、HTTPS 域名及真机核对微信登录、头像昵称选择与上传、网页老用户绑定、排盘、历史详情、删除和禁用账号。仓库不包含这些生产凭证，因此本地自动测试使用模拟微信接口。

公开的管理员注册接口已移除；若数据库还没有管理员，可在可信终端从 `backend/` 执行 `ADMIN_INIT_EMAIL=... ADMIN_INIT_NAME=... go run ./cmd/admininit`，按提示输入至少 12 位密码。此命令仅在管理员表为空时创建首个管理员。

## 打开方式

在微信开发者工具中导入本目录 `miniapp/`。真实微信登录需要与后端配置一致的小程序 AppID。

本机开发者工具已打开择日页，WXML/WXSS 编译通过；默认列表与展开日期的模拟器画面已核对。真机和更窄屏幕仍需单独检查。

页面包含首页真实排盘／历史切换、独立干支结果页、日历、择日参考、我的和个人资料编辑页。排盘需要先登录；历史卡片可查看详情和删除。网页账号绑定可在微信登录后从个人中心选择。

跨页入口点击后会立即显示按压状态；若跳转超过 200 毫秒才显示浅金色「正在打开…」，页面就绪或返回时自动消失。失败或超时会提示重试，并恢复入口。择日页面切换事项和日期范围时，筛选项与结果一起更新；若结果视图更新较慢，结果区域会显示「日期结果更新中…」，超时后可点击「重新显示」。月历标签使用随包数据，择日参考通过服务端读取日期范围资料。

日历所选日期下方新增「每日干支参考」入口。点击「使用示例干支体验」后，摘要会随选日更新；点击摘要可进入独立详情页，查看固定示例干支的扶抑喜忌、当天干支关系和搬家／财务安排提醒。详情页可结束体验，回到日历的未启用状态。体验状态只保存在小程序当前运行进程内。

日历选中日期卡和「每日干支参考」详情页还展示建除十二值星（建、除、满、平、定、执、破、危、成、收、开、闭）及简短字义。数据由项目现有 `lunar-go` 的 `GetZhiXing()` 随静态日历一起生成；建除是通用日期标签，不参与当前示例干支关系或事项提醒的计算。

日历页提供一处「择日参考」入口。择日页可选搬家、结婚、开业、出行或动土；默认搬家，从北京时间当天起查看 30 个日历日。自定义起止日期按需展开，范围可在 1900—2100 年内选择，一次最多 90 天。五项分别按通用宜忌中的「入宅／移徙」「嫁娶」「开市」「出行」「动土」原始标签筛选；「诸事不宜」对所有事项标记冲突。「开业」只按「开市」标签筛选，不延伸为交易或投资时机。

结果按「有相关宜／有相关忌／未列相关标签」分组，一次只显示一个分组，切换分组无需重新请求。默认查看「有相关宜」，每组先显示 5 个简洁日期条目，可逐次继续显示直到全部日期可访问。点开日期可核对事项命中标签、分组原因和完整通用宜忌；绑定本人命盘后还可另行打开同日的个人每日参考。切换事项会保留日期范围，并重置结果分组与已展开日期。

核对筛选时，相关忌优先于相关宜；两侧均未命中时列入「未列相关标签」，不推断适宜与否。将起日设得晚于止日，或选择超过 90 天的范围，应显示错误且清空旧结果。

## 数据边界

小程序真实排盘展示基本排盘、天干级与扶抑喜忌、命格，并保存历史。登录用户可在历史记录中主动将自己的一份排盘设为「本人命盘」，也可更换或解绑；登录和排盘都不会自动绑定。绑定后，日历所选日期的「每日干支参考」由后端按本人命盘计算。小程序当前不包含 AI 干支或 AI 报告。

首页和真实每日详情的本人区域固定展示人际往来、财星参考、桃花缘分、作息节奏四主题；有明确个人信号时显示“宜／慎”，未触发特别规则时显示“平”及检查依据。详情可展开依据和行动建议。财星参考只涉及研究、预算及风险核对；作息节奏仅在日干和日支主气均为忌神时提示“慎”，建议只涉及一般作息与活动节奏，不以日支相冲推断健康风险，也不预测交易收益、疾病或意外。通用黄历宜忌仍单列，不转换为个人结论。

「每日干支参考」保留固定示例体验，并明确标为演示。真实个人模式使用账号绑定的排盘、服务端当天干支、扶抑喜忌、十神和日支关系，展示依据及有限事项提醒。喜忌方向不能直接推断为「今日破财」等确定事件；此功能不属于完整择日，也不提供投资买卖建议。未绑定用户仍可查看通用日历或主动体验固定示例。

「择日参考」使用服务端真实通用日期资料，但不评估时辰、方位、参与人干支或实际安排，也没有五事项各自的完整择日规则。它不输出吉凶分数或「最佳吉日」，也不把「求财」「交易」映射成投资买卖时机。本人每日参考与通用事项筛选分开展示，不合成单一结论。

八字查询会调用后端真实排盘并保存干支；首页历史、详情和我的统计读取当前登录用户的数据，删除会调用后端接口。日历的 2025—2027 年月历标签由项目现有 `lunar-go` 库预先生成并随小程序打包；绑定后的所选日期个人参考由后端计算，支持演示年份之外的日期。择日参考按服务端通用宜忌筛选，不能解释为当前登录用户的个人择日结果。日期选择器仅展示到小时，分钟固定为 `00`，与现有排盘接口的精度一致。

若要重新生成图标或日历静态数据：

```bash
python3 miniapp/tools/generate_tab_icons.py
cd backend
go run ../miniapp/tools/generate_demo_calendar.go ../miniapp/data/calendar.js
go run ../miniapp/tools/generate_demo_chart.go ../miniapp/data/demo_chart.js
```
