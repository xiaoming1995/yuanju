# 缘聚小程序界面原型

根据「干支万年历应用界面展示稿」制作的微信小程序原生前端，用于查看界面效果与基础交互。

## 打开方式

在微信开发者工具中导入本目录 `miniapp/`。项目配置使用 `touristappid` 供本机体验；如需真机预览，应换成实际小程序 AppID 并使用对应开发者账号。

本机开发者工具曾成功打开该项目，模拟器日志确认首页、日历与结果页加载。独立结果页的跳转与返回已通过代码交互检查。择日页的交互检查已通过，但开发者工具 CLI 打开项目时返回 `ERR_SOCKET_BAD_PORT 65536`；新增的命盘核心结论卡、五事项页面及本轮字号/列表调整尚未取得模拟器画面，请在开发者工具中点击「编译」并检查窄屏排版和真机显示。

页面包含首页干支演示／历史切换、独立固定示例结果页、日历、择日参考和我的。可试用日期选择、查看固定示例结果、返回修改日期、历史卡片查看与临时移除、日历切月／选日和工具入口反馈。在「我的」页点击「预览登录后界面」可查看登录态设计效果，再点击「退出演示登录」返回未登录状态。

跨页入口点击后会立即显示按压状态；若跳转超过 200 毫秒才显示浅金色「正在打开…」，页面就绪或返回时自动消失。失败或超时会提示重试，并恢复入口。择日页面切换事项和日期范围时，筛选项与结果一起更新；若结果视图更新较慢，结果区域会显示「日期结果更新中…」，超时后可点击「重新显示」。本原型均使用随包本地数据，静态页面没有额外的网络加载占位。

日历所选日期下方新增「每日干支参考」入口。点击「使用示例命盘体验」后，摘要会随选日更新；点击摘要可进入独立详情页，查看固定示例命盘的扶抑喜忌、当天干支关系和搬家／财务安排提醒。详情页可结束体验，回到日历的未启用状态。体验状态只保存在小程序当前运行进程内。

日历选中日期卡和「每日干支参考」详情页还展示建除十二值星（建、除、满、平、定、执、破、危、成、收、开、闭）及简短字义。数据由项目现有 `lunar-go` 的 `GetZhiXing()` 随静态日历一起生成；建除是通用日期标签，不参与当前示例命盘关系或事项提醒的计算。

日历页顶部「择日」和选中日期卡下方「择日参考」都能进入独立页面。先选搬家、结婚、开业、出行或动土，再选择起止日期；默认搬家、从当天起查看 30 个日历日，最多一次查看 90 天，范围限于本地 2025—2027 年数据。五项分别读取 `lunar-go` 每日宜忌的「入宅／移徙」「嫁娶」「开市」「出行」「动土」原始标签；通用忌「诸事不宜」对全部事项标记冲突。页面直接显示映射，尤其说明「开业」只按「开市」标签演示，不延伸为交易或投资时机。

启用固定示例命盘后，页面按「通用宜与示例关系同向／有通用宜，仍需核对／有通用宜忌冲突／依据不足」分组展示范围内的日期。每组先显示 7 天，可逐次继续显示直到全部日期可访问。个人依据复用「每日干支参考」的通用简化关系，建除只作补充展示；两者都不是事项专属择日规则。切换事项会保留日期范围并重新计算，同时重置列表展开状态；点击日期卡可查看同一天的事项原始标签和通用命盘关系，返回后保留事项和范围。

可用以下日期检查搬家演示结果：2026-10-22 的「忌入宅」应出现在冲突组；2026-10-23 有「宜入宅、宜移徙」但示例命盘关系复杂，应出现在需核对组；2026-11-16 有两个相关宜标签且示例关系偏合，应出现在「通用宜与示例关系同向」组。切换到结婚、开业、出行或动土后，页面应保留范围但重算结果。将起日设得晚于止日，或选择超过 90 天的范围，应显示错误且清空旧结果。

## 数据边界

小程序当前展示固定示例的干支查询、基础排盘、天干级与扶抑喜忌、命格、日历和历史记录，不包含 AI 命盘或 AI 报告。

「每日干支参考」也是原型演示：固定命盘的扶抑喜忌由现有 Go 排盘引擎生成，所选日期标签来自本地日历。页面仅比较日干、日支主气与示例命盘的扶抑方向，并提示日支相冲；它不接入真实账号或出生资料绑定，不属于完整择日，也不提供投资买卖建议。

「择日参考」同样是前端原型，不评估时辰、方位、参与人命盘或实际安排，也没有结婚、开业、出行、动土各自的完整规则。它不输出吉凶分数或「最佳吉日」，也不把「求财」「交易」映射成投资买卖时机。通用宜忌与个人关系冲突时，页面会保留两边的原始依据供核对，不合成单一结论。

这是**前端原型**。查看示例结果不会调用排盘接口、登录或保存历史。登录态只在当前小程序页面内切换，示例邮箱、统计及最近命盘均不读取真实账号。结果页会显示本次选择的日期与备注，并明确区分固定的示例命盘。该命盘使用项目现有 Go 排盘引擎按 1990-01-01 01:00、男命、北京时间预先生成；「基本排盘」字段顺序与网页端一致，五行统计、天干级与扶抑喜忌、命格均来自同一结果。历史卡片仍为设计稿示例，删除会同步更新首页与我的当前进程内的演示列表，重新打开小程序恢复原样。日历的 2025—2027 年日期标签由项目现有 `lunar-go` 库预先生成并随小程序打包，不请求服务器。日期选择器仅展示到小时，分钟固定为 `00`，与现有排盘接口的精度一致；正式版需另行决定分钟的业务语义。

```bash
cd backend
go run ../miniapp/tools/generate_demo_calendar.go ../miniapp/data/calendar.js
go run ../miniapp/tools/generate_demo_chart.go ../miniapp/data/demo_chart.js
```
